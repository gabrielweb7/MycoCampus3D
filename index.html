📖 Guia de Jogabilidade

🖥️ PC

WASD para andar, mouse para olhar, clique para interagir, Shift para correr, Espaço para pular, R ou roda do mouse para girar um item e G/Q para soltá-lo.

📱 Celular

Joystick para andar, arraste a tela para olhar e use os botões na direita para agir, girar, correr ou pular. O botão de ação mostra um ícone de acordo com o alvo.

Dica: mire em um item ou equipamento para ver a ação disponível. Se não puder usar a ferramenta naquele alvo, a mensagem informa o que está faltando.
